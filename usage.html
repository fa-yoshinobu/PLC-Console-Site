アプリの使い方

Project Builderでの設定作成から、QRコード転送、PLCへの接続、IO確認・書き込みまで、画面ごとにステップで解説します。

STEP 01 Project Builder

Project Builder を起動する

ダウンロードした PlcIoCheckerQr.exe をダブルクリックするだけで起動します。インストール不要です。

初回起動時: Windows SmartScreen が表示された場合は「詳細情報」→「実行」をクリックしてください。
  • EXEのインストール不要 — ダブルクリックで起動
  • Windows 10 / 11 (x64) 対応
  • 日本語・English を起動後に切替可能
  • 無料（MITライセンス）
Windows PC .NET 8.0 内蔵 無料

STEP 02 Project Builder

PLC接続設定を入力する

「新規」ボタンでプロジェクトを作成し、PLC接続情報を入力します。

項目 説明
PLCベンダー Mitsubishi MELSEC / KEYENCE KV
IPアドレス PLCのEthernetモジュールのIP
ポート番号 MELSEC: 5001 / KEYENCE: 8501
プロトコル UDP（MELSEC推奨）/ TCP（KEYENCE推奨）
詳しいPLC設定手順は 技術ガイド — PLC設定 を参照してください。

STEP 03 Project Builder

監視デバイスを登録する

IOチェック対象のデバイスアドレスとデータ型を登録します。Excelのアドレス列をそのままコピー&ペーストできます。

  • デバイス一覧 — アドレス + データ型 + コメント
  • タイムチャート — 波形記録したいアドレスを最大20ch登録
  • トラップルール — 監視条件（Rise/Fall/Change/比較）
Excelコピペ対応: IOリスト表のアドレス列を選択してコピーし、Project Builderのデバイスリストに貼り付けると一括登録できます。

設定サンプル（用途別IOリスト）は 設定サンプル ページをご覧ください。

STEP 04 Project Builder

QRコードを生成する

「QRコード生成」ボタンをクリックすると、設定が圧縮されたQRコードが表示されます。デバイス数が多い場合は複数枚に分割されます。

  • 1枚でスキャンできるサイズに自動分割
  • PNG画像としてエクスポート（メール送付・印刷に便利）
  • JSONファイルとしてエクスポート・バックアップも可能
QRが読み取りにくい場合: チャンクサイズを小さく（例: 800→400）するとQRの密度が下がり、スキャンしやすくなります（枚数は増えます）。

STEP 05 スマートフォン

アプリでQRコードをスキャンする

アプリを起動して「QRスキャン」を選択し、Project Builderで生成したQRコードをカメラで読み取ります。

  • 複数枚のQRはどの順番でスキャンしても自動結合
  • スキャン完了後、設定内容を確認してプロジェクト保存
  • PCのモニターに表示されたQRをそのままスキャン可能
  • PNG出力したQRを印刷してスキャンも可能
カメラ権限の確認: 初回スキャン時にカメラ使用の許可が求められます。「許可」を選択してください。

STEP 06 スマートフォン

PLCに接続する

スマートフォンをPLCと同一Wi-Fiに接続し、アプリ上部の「接続」ボタンをタップします。接続に成功すると、ステータスバーにPLC型式とIPアドレスが表示されます。

  • 同一ネットワークのWi-Fi接続が必要（工場LAN対応）
  • 接続成功: ステータスバーに型式・IP表示
  • 接続失敗: エラーメッセージで原因を確認
デモモード: 実機PLCなしで全機能を試したい場合は「デモモード」を選択してください。シミュレーション値で動作します。

STEP 07 スマートフォン

デバイス一覧でIOを確認する

登録したすべてのデバイスの現在値がリアルタイムで一覧表示されます。グループタブ・フィルタ・検索で目的のデバイスをすばやく見つけられます。

  • ビット: ON/OFFを色で視覚的に確認
  • ワード/Float: 現在値を数値表示
  • フィルタでデバイス種別（X/Y/M/D等）を絞り込み
  • コメント（ラベル）表示でデバイスを識別
ブロックビュー: 「ブロック」タブに切り替えると、連続アドレスをグリッド表示で一括確認できます。配線チェックに最適です。

STEP 08 スマートフォン

デバイスの値を書き込む（フォーカスパネル）

デバイスをタップするとフォーカスパネルが開きます。ビットのON/OFF操作や、ワードデバイスへの数値書き込みができます。

  • ビット: ON/OFFトグルボタン or 長押し確認モード
  • ワード: 数値キーパッドで入力して書き込み
  • データ型を切り替えて表示値を変換可能
  • プラス/マイナスボタンで値を増減
注意: 書き込み操作はPLC出力に即時反映されます。設備の安全を確認してから操作してください。

STEP 09 スマートフォン

タイムチャートで波形を確認する

「チャート」タブに切り替えると、登録した最大20chのデバイス値が波形グラフで表示されます。動作タイミングの確認や、信号の遅延チェックに役立ちます。

  • 最大20ch 同時表示
  • 500msサンプリング・約500秒バッファ
  • スワイプで過去データを遡って確認
  • CSVエクスポート（タイムスタンプ付き）

STEP 10 スマートフォン

トラップでアラートを確認する

「トラップ」タブでは、Project Builderで設定した条件が成立したイベントが時系列で記録されます。立ち上げ中の異常信号の記録・解析に活用できます。

  • Rise / Fall / Change / 閾値比較でイベント検知
  • タイムスタンプ + デバイスアドレス + 値を記録
  • CSVエクスポートで解析・帳票に活用
活用例: 立ち上げ中にエラー信号（M100等）を監視し、どのタイミングで発生したか履歴を取得→原因特定に活用。
