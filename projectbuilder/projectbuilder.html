PC Tool

ProjectBuilder

PC で PLC IO Checker のプロジェクトを作成し、Android / iOS アプリへ案件として QR または JSON で転送するためのツールです。

公開ページ

ProjectBuilder の exe は GitHub の PlcIoChecker_ProjectBuilder Releases を開き、対象リリースの Assets にある PlcIoCheckerProjectBuilder-win-x64.zip をダウンロードします。README やソースは PlcIoChecker_ProjectBuilder で確認します。

主な用途

PLC 設定

メーカー、CPU model、IP、ポート、TCP/UDP、ルート指定を PC で入力します。

デバイス登録

アドレス / Data type / Comment を表形式で登録します。Excel からの貼り付けにも向いています。

QR/JSON 出力

作成したプロジェクトを QR ページまたは JSON ファイルとして出力します。

MELSEC プロジェクト

接続設定

CPU モデル、IP、ポート、Transport、network/station/module_io/multidrop、リモートパスワードを設定します。

JSON 出力

networkNo / stationNo は 10 進、moduleIoNo / multidropNo は 0x 付き 16 進で出力します。

デバイス

MELSEC の CPU ファミリに応じたデバイスを検証します。iQ-F の X / Y は 8 進表記です。

KEYENCE プロジェクト

接続設定

モデル、IP、ポート、Transport、KEYENCE 表示モードを設定します。リモートパスワードは出力しません。

KEYENCE 表示

Normal と XYM を選べます。選択した表示モードで、デバイス / タイムチャート / トラップのアドレス検証が行われます。

デバイス

Normal では R、DM など、XYM では X、Y、M などの表記を扱います。

基本手順

  1. ProjectBuilder を起動するPlcIoCheckerProjectBuilder.exe を起動します。
  2. プロジェクトと PLC を設定するプロジェクト名、メーカー、CPU model、IP、ポート、Transport を入力します。
  3. デバイスを登録する監視するアドレス、Data type、Comment を登録します。
  4. タイムチャート / トラップを登録する必要に応じて記録対象や検知条件を登録します。
  5. QR または JSON を出力するモバイルアプリの QR読込または JSON読込で取り込みます。

QR 出力の注意

  • QR は大きく表示してください。
  • 複数枚の場合、アプリがすべてのページを読み込むまで順番に表示します。
  • 読み取りにくい場合は QR 1枚の文字数を下げて、枚数を増やします。
  • 現在の QR 形式は PLCIOC3|ZSTD です。

配布とライセンス

ProjectBuilder は GitHub で公開されている PC 用ツールです。ProjectBuilder 自体の変更履歴は GitHub Releases を確認します。PLC IO Checker アプリのリリースノートには ProjectBuilder の更新履歴を混ぜません。

ProjectBuilder のソースは MIT license で公開されています。モバイルアプリの販売条件、アプリ内購入、ストア返金条件とは別の扱いです。
