PC Tool

ProjectBuilder

PC で PLC IO Checker のプロジェクトを作成し、Android / iOS アプリへ QR または JSON で転送するためのツールです。

公開ページ

ProjectBuilder の exe は GitHub の PlcIoChecker_ProjectBuilder Releases を開き、対象リリースの Assets にある PlcIoCheckerProjectBuilder-win-x64.zip をダウンロードします。README やソースは PlcIoChecker_ProjectBuilder で確認します。

主な用途

PLC 設定

メーカー、CPU機種、IP、ポート、Transport、MELSEC ルーティングを PC で入力します。

デバイス登録

アドレス / データタイプ / Comment を表形式で登録します。Excel からの貼り付けにも向いています。

QR/JSON 出力

作成したプロジェクトを QR ページ、QR PNG、JSON ファイルとして出力します。

MELSEC プロジェクト

接続設定

CPU機種、IP address、Port、Transport、Network、Station、Module I/O、Multidrop を設定します。リモートパスワードは ProjectBuilder では扱わず、モバイルアプリ側で入力します。

Routing 表記

Network / Station は数字で、Module I/O / Multidrop は画面の初期表示と同じ 0x 付きで入力します。

デバイス

iQ-F の X / Y は 8 進表記です。B、W、SB、SW は 16 進表記です。

KEYENCE プロジェクト

接続設定

モデル、IP、ポート、Transport、KEYENCE 表示を設定します。

KEYENCE 表示

Normal と XYM を選べます。使用するアドレス表記に合わせて選択します。

デバイス

Normal では R、DM など、XYM では X、Y、M などの表記を扱います。

基本手順

  1. ProjectBuilder を起動するPlcIoCheckerProjectBuilder.exe を起動します。
  2. プロジェクトと PLC を設定するプロジェクト名、メーカー、CPU機種、IP、ポート、Transport を入力します。
  3. デバイスを登録する監視するアドレス、データタイプ、Comment を登録します。
  4. タイムチャート / トラップを登録する必要に応じて記録対象や検知条件を登録します。
  5. QR または JSON を出力するQR 生成、ファイル メニュー、QR メニューを使い、モバイルアプリの QR読込または JSON読込で取り込みます。

QR 出力の注意

  • QR は大きく表示してください。
  • 複数枚の場合は 前へ / 次へ で切り替えるか、自動 で自動切換えします。
  • 読み取りにくい場合は QR メニューの 分割サイズ を下げて、1枚あたりの文字数を少なくします。
  • PNG + JSON 保存 は QR メニューから実行します。

配布とライセンス

ProjectBuilder は GitHub で公開されている PC 用ツールです。ダウンロードは GitHub Releases を確認します。
