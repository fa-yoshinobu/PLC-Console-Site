ProjectBuilder

ProjectBuilder 入力

Devices、Time Chart、Traps を PC で入力し、モバイルアプリに渡す案件を作成します。

Devices

Address
監視する PLC デバイスアドレスです。
Data type
BIT、INT16、UINT16、INT32、UINT32、FLOAT32
Comment
任意のコメントです。同じ address が複数ある場合、最初の非空 comment が同じ address に反映されます。

Excel からタブ区切りでコピー/貼り付けできます。ブロック追加では開始アドレスと点数を指定します。

Time Chart

モバイルアプリの Time Chart に表示する対象を登録します。最大 20 チャンネルです。

Address
記録対象のアドレスです。
Data type
Devices に同じ address があればその data type を優先します。

Traps

条件に一致したタイミングを検知する定義です。最大 20 件です。

Address / Data type
検知対象と data type です。
Condition
BIT は Rise、Fall、Change。WORD は Change、GreaterOrEqual、LessOrEqual、Equal、NotEqual。
Threshold
比較条件で必要です。
Enabled
有効/無効を指定します。

検証

Vendor、CPU model、KEYENCE 表示に応じてデバイスと data type を検証します。対応しない address や condition は生成時または読み込み時にエラーになります。
