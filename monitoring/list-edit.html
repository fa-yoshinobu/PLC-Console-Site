List Editor

List 登録編集

List に表示するデバイスを登録・編集する画面です。Time Chart や Trap の登録とは別です。

入口と実行条件

  • 入口は List 画面の List 登録編集 です。ハンバーガーメニューには置きません。
  • 案件が開いている状態で使用します。
  • 登録したデバイスは List 監視に表示され、コメントも List / Block の詳細表示で使われます。

追加・一括操作

デバイス追加

単体アドレスを追加します。BIT デバイスは BIT、WORD デバイスは既定で INT16 として扱います。

範囲追加

開始アドレスと終了アドレスを指定して連続範囲を追加します。

範囲削除

指定範囲の登録済みデバイスを削除します。削除前に確認が表示されます。

登録済みデバイス

  • 検索でアドレスやコメントを絞り込めます。
  • 各行で comment を編集できます。
  • 上へ / 下へで表示順を変更できます。
  • 保存で行の編集を反映し、削除で行を消します。

失敗時の確認

追加できない場合は、選択中の PLC 種別、CPU model、KEYENCE デバイス表記、アドレス表記、data type を確認してください。
