List Editor

List 登録編集

List に表示するデバイスを登録・編集する画面です。タイムチャートやトラップの登録とは別です。

入口と実行条件

  • 入口は List 画面の List 登録編集 です。ハンバーガーメニューには置きません。
  • 登録編集は全画面で開きます。登録件数が多い場合でも、一覧と編集操作を同じ画面内で確認できます。
  • プロジェクトが開いている状態で使用します。
  • 登録したデバイスは List 監視に表示されます。コメントはアドレス単位のコメントDBへ保存され、List / Block / デバイス操作パネル / TimeChart 登録 / Trap 登録・編集で共通表示されます。

追加・一括操作

デバイス追加

単体アドレスを追加します。BIT デバイスは BIT、WORD デバイスは既定で INT16 として扱います。

範囲追加

開始アドレスと終了アドレスを指定して連続範囲を追加します。

範囲削除

指定範囲の登録済みデバイスを削除します。削除前に確認が表示されます。

登録済みデバイス

  • 検索でアドレスやコメントを絞り込めます。
  • 各行で comment を編集できます。保存したコメントは同じアドレスの共通コメントとして扱われます。
  • 上へ / 下へで表示順を変更できます。ドラッグによる並び替えは使いません。
  • 保存で行の編集を反映し、削除で行を消します。

失敗時の確認

追加できない場合は、選択中の PLC 種別、CPU機種、KEYENCE デバイス表記、アドレス表記、データタイプを確認してください。
