コメント

デバイスの表示名として使うコメントを CSV または PLC から読み込み、アドレス単位の共通コメントとして保存します。

コメントの読み込み方法

CSVコメント読込

アドレスとコメントを含む CSV を読み込みます。PC で作成したコメント表を端末へ取り込む用途に向いています。

CSVコメント読込を確認する

コメント読込

KEYENCE プロジェクトで接続中の場合、PLC からデバイスコメントを読み込めます。接続していない状態、または対応しない接続では実行できません。

コメント読込を確認する

MELSEC / KEYENCE の違い

MELSEC

CSVコメント読込 を使用します。PLC から直接コメントを読むメニューは MELSEC では表示されません。

KEYENCE

CSVコメント読込 に加えて、接続中は コメント読込 で PLC からコメントを取得できます。メニューから範囲読込、デバイス操作パネルから個別読込を使えます。

読み込み後の確認

  • List / Block / デバイス操作パネル / TimeChart 登録 / Trap 登録・編集でコメント表示が更新されます。
  • 読み込めなかった行がある場合は、行番号と理由の表示やエラー履歴を確認してください。
  • CSV や PLC から読み込んだコメントは端末内のコメントDBに保存され、同じプロジェクトの表示に反映されます。
  • CSV の文字コードや列順が合わない場合は、ProjectBuilder 側で整理してから再読込してください。
