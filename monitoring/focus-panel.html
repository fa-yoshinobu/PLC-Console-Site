トップ操作パネル

Focus Panel

操作パネル

List / Block で選択したデバイスの現在値確認、書込、Time Chart / Trap への追加を行います。

表示条件

  • PLC 接続中に List の行、または Block のセル/行をタップすると開きます。
  • 縦向きでは下部シート、横向きでは右側ペインとして表示されます。
  • Block のページ移動、開始番号ジャンプ、ブロック選択だけでは自動で開きません。

BIT デバイス

ON / OFF

ON / OFF の操作で BIT 値を書き込みます。

書込ロック

上部の書込ロックを解除してから操作します。ロック中は書込操作が無効になります。

長押し

ビット書き込み設定が長押しの場合、進行表示が完了するまで押し続けます。

WORD デバイス

  • Type から Int16、UInt16、Int32、UInt32、Float32 を選びます。
  • DEC、HEX、BIT の表示/入力モードがあります。
  • 2 word 型が範囲末尾で使えない場合、その型は選択できません。
  • BIT 編集モードでは現在値の bit を編集して書込できます。

追加導線

List
選択デバイスを List 登録へ関連づける導線です。
Time Chart
選択デバイスを Time Chart のチャンネルへ追加します。最大 20 チャンネルです。
Trap
選択デバイスの Trap 登録を開きます。最大 20 件で、既に登録済みのアドレスでは追加できません。
前へ: List 登録編集 次へ: 書込
