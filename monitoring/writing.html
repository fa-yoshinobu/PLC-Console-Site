Write

書込

デバイスへの書込はロック解除後、長押し確認で実行します。実設備へ影響するため慎重に操作してください。

書込前の確認

対象 PLC、アドレス、データ型、値が正しいことを確認してください。アプリはラッチクリア操作を自動実行しません。

書込手順

  1. 対象を選ぶブロックまたはリストから書き込みたいデバイスをタップします。
  2. 値を確認するBIT の ON/OFF、数値のデータ型、入力値を確認します。
  3. ロックを解除する上部の解除ボタンで書込ロックを解除します。
  4. 長押しで確定する進行表示が完了するまで押し続けると書込が実行されます。

CPU 操作

メニューの CPU操作 から CPU 状態の変更を送信します。PLC 側の権限や設定によって失敗する場合があります。

MELSEC

RUN、STOP、PAUSE を表示します。PAUSE は MELSEC で使用する操作です。

KEYENCE

RUN と PROGRAM を表示します。アプリ内の停止表示は KEYENCE では PROGRAM です。
