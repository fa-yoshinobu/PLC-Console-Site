設定サンプル

用途別・機種別のデバイス設定例です。Project Builder への入力の参考にご利用ください。

⚠️ 注意: こちらのサンプルはあくまで参考例です。実際のデバイスアドレスは機種・プログラムによって異なります。必ず実機のPLCプログラムを確認してから設定してください。

搬送コンベア

ベルトコンベアや搬送ラインの立ち上げに。センサー入力・モーター出力・速度データ・エラーフラグを網羅したサンプルです。

接続設定

CPUiQ-R (R08CPU等)
IP192.168.1.10
Port5001
ProtocolUDP
Timeout1000 ms

X1Bit緊急停止 (EMG)入力
X2Bit光電センサー1（搬入口）入力
X3Bit光電センサー2（搬出口）入力
X4Bit近接センサー（定位置）入力
X5Bitインバータ故障入力
X6Bitモータ過負荷 (OL)入力
X7Bitドアインターロック入力
Y0Bitコンベアモータ 正転出力
Y1Bitコンベアモータ 逆転出力
Y2Bitブレーキ解放出力
Y3Bit運転表示灯（緑）出力
Y4Bit異常表示灯（赤）出力
M0Bit自動運転モード内部
M1Bitエラー発生フラグ内部
M2Bitワーク搬送中フラグ内部
M10Bitサイクルスタート内部
D0UInt16コンベア速度指令 (rpm)データ
D1UInt16コンベア速度フィードバック (rpm)データ
D2UInt16ワーク搬送カウントデータ
D3UInt16エラーコードデータ
D10Int32累計搬送数（32bit）データ
D20Float32モータ電流値 (A)データ
MELSEC iQ-R の X/Y アドレスは 16進数（X0〜X7 = X00〜X07）。D は 10進数。
chアドレスデータ型説明
ch 1D0UInt16速度指令 (rpm)
ch 2D1UInt16速度フィードバック (rpm)
ch 3D20Float32モータ電流 (A)

ch 5X3Bit光電センサー2
ch 6Y0Bitモータ正転出力
ch 7M1Bitエラーフラグ

速度指令と速度FBの波形を並べて表示することで、インバータの追従性・応答遅れを確認できます。
アドレス条件しきい値コメント
X1Rising Edge—緊急停止 発生
X5Rising Edge—インバータ故障 発生
X6Rising Edge—モータ過負荷 発生
M1Rising Edge—エラーフラグ ON
M1Falling Edge—エラーフラグ クリア
D3Change—エラーコード 変化
D20>=5.0モータ電流過大（5A超え）
D1<=100速度低下（100rpm以下）
緊急停止やインバータ故障の発生タイミングをトラップで記録し、CSVで解析できます。
📋 使い方: Project Builderの各タブにこの設定を入力 → QRコード生成 → アプリでスキャン。アドレスは実機PLCプログラムに合わせて変更してください。

射出成形機

射出成形機の立ち上げ・調整時のIOチェックサンプル。温度・圧力・位置データや成形サイクルの信号を監視します。

KEYENCE KV-8000 HostLink / TCP Port: 8501

接続設定

ベンダーKEYENCE
機種KV-8000
IP192.168.1.20
Port8501
ProtocolTCP
Timeout2000 ms
アドレスデータ型コメント（ラベル）用途
R0Bit成形機 運転中入力
R1Bit成形機 異常入力
R2Bit型閉完了入力
R3Bit型開完了入力
R4Bit射出完了入力
R5Bit計量完了入力
R6Bitエジェクタ 前進完了入力
R7Bitエジェクタ 後退完了入力
MR0Bitサイクル開始内部
MR1Bit異常フラグ内部
DM0Int16バレル温度 ゾーン1 (×0.1℃)データ
DM1Int16バレル温度 ゾーン2 (×0.1℃)データ
DM2Int16ノズル温度 (×0.1℃)データ
DM3Int16金型温度 固定側 (×0.1℃)データ
DM4Int16金型温度 可動側 (×0.1℃)データ
DM10UInt16射出圧力 (kgf/cm²)データ
DM11UInt16保圧圧力 (kgf/cm²)データ
DM12UInt16スクリュ位置 (mm)データ
DM20UInt16成形ショット数データ
DM21UInt16サイクルタイム (×0.1s)データ
DM30UInt16異常コードデータ
KEYENCE KV-8000 の R / MR はビットデバイス、DM はワードデバイス。温度は ×0.1 で実値に変換。
chアドレスデータ型説明
ch 1DM0Int16バレル温度1 (×0.1℃)
ch 2DM1Int16バレル温度2 (×0.1℃)
ch 3DM2Int16ノズル温度 (×0.1℃)
ch 4DM10UInt16射出圧力
ch 5DM12UInt16スクリュ位置 (mm)
ch 6R4Bit射出完了信号
ch 7MR1Bit異常フラグ
温度・圧力・位置の同時記録により、成形サイクルの各フェーズを視覚的に把握できます。
アドレス条件しきい値コメント
R1Rising Edge—成形機 異常発生
MR1Rising Edge—異常フラグ ON
DM30Change—異常コード 変化
DM0>=2800バレル温度1 過高温（280.0℃超）
DM0<=2300バレル温度1 低温（230.0℃未満）
DM10>=1500射出圧力 過大
温度の異常変動を自動検知し、成形不良の原因特定に活用できます。
📋 温度データは倍率（×0.1）に注意。DM0の実値は DM0 ÷ 10 = 実温度(℃) です。

Port5001
ProtocolUDP
Timeout1000 ms
アドレスデータ型コメント（ラベル）用途
X0Bitロボット 運転可信号入力
X1Bitロボット 動作中入力
X2Bitロボット 原点復帰完了入力
X3Bitロボット エラー入力
X4Bit安全ドア 閉確認入力
X5Bitライトカーテン 安全入力
X6Bitワーク供給センサー入力
X7Bitワーク排出センサー入力
X10Bitハンド 把持確認入力
X11Bitハンド 開放確認入力
Y0Bitロボット 起動信号出力
Y1Bitロボット 一時停止出力
Y2Bitハンド 把持出力
Y3Bitハンド 開放出力
M0Bitセル 自動運転中内部
M1Bitセル エラー内部

D2UInt16サイクルカウントデータ
D3UInt16サイクルタイム (×10ms)データ
FX5U の X/Y アドレスは 8進数（X0〜X7, X10〜X17...）。

ハンド出力とハンド確認入力のタイムラグを波形で確認することで、センサーの動作遅延を把握できます。
アドレス条件しきい値コメント
X3Rising Edge—ロボットエラー 発生
M1Rising Edge—セルエラー 発生
D1Change—ロボットエラーコード 変化
X4Falling Edge—安全ドア 開 (インターロック)

D3>=500サイクルタイム 5秒超
安全回路の遮断タイミングとロボット停止のタイムラグを記録し、安全機能の動作確認に活用できます。
📋 安全ドアやライトカーテンのトラップは、インターロック動作の検証に特に有効です。

巻取機

フィルム・シート・線材等の巻取設備の立ち上げサンプル。張力・速度・径の管理データを監視します。

Mitsubishi MELSEC Q系 (QJ71E71-100) SLMP / UDP Port: 5001

接続設定

ベンダーMELSEC
CPUQ系 (Q06UDV等)
IP192.168.1.40
Port5001
ProtocolUDP
Timeout1000 ms
アドレスデータ型コメント（ラベル）用途
X0Bit運転信号入力
X1Bit停止信号入力
X2Bit満巻センサー入力
X3Bit張力過大センサー入力
X4Bit張力不足センサー入力
Y0Bit巻取モータ 運転出力
Y1Bitブレーキ出力
M0Bit自動運転中内部
M1Bitエラー内部
D0UInt16ライン速度指令 (m/min×10)データ
D1UInt16ライン速度実績 (m/min×10)データ
D2UInt16張力実績 (N×10)データ
D3UInt16張力指令 (N×10)データ
D4UInt16巻径計算値 (mm)データ
D5UInt16巻取モータ速度 (rpm)データ
D10Int32巻取長さ (m×100)データ
速度・張力の単位換算に注意（倍率は機種・プログラムによって異なります）。
chアドレスデータ型説明
ch 1D0UInt16速度指令
ch 2D1UInt16速度実績
ch 3D2UInt16張力実績
ch 4D3UInt16張力指令
ch 5D4UInt16巻径
ch 6Y0Bitモータ運転
ch 7X3Bit張力過大
速度指令と張力の相関を波形で確認することで、テーパー張力制御の調整に活用できます。
アドレス条件しきい値コメント
X2Rising Edge—満巻 検出
X3Rising Edge—張力過大 発生
X4Rising Edge—張力不足 発生
M1Rising Edge—エラー 発生
D2>=1200張力 過大閾値超え
D2<=200張力 過小閾値割れ
📋 速度と張力を同時にタイムチャートで記録することで、加速・減速時の張力変動パターンを調整できます。

搬送装置（多軸）

XYZステージ・スライダ・シリンダを組み合わせた多軸搬送装置の立ち上げサンプル。各軸の位置・原点・速度を監視します。

KEYENCE KV-7000 / KV-7500 HostLink / TCP Port: 8501

接続設定

ベンダーKEYENCE
機種KV-7000
IP192.168.1.50
Port8501
ProtocolTCP
Timeout2000 ms
アドレスデータ型コメント（ラベル）用途
R0BitX軸 原点完了入力
R1BitY軸 原点完了入力
R2BitZ軸 原点完了入力
R3BitX軸 位置決め完了入力
R4BitY軸 位置決め完了入力
R5BitZ軸 位置決め完了入力
R6BitX軸 + リミット入力
R7BitX軸 - リミット入力
R8BitY軸 + リミット入力
R9BitZ軸 - リミット（下降端）入力
R10Bitハンド 真空確認入力
MR0Bit自動運転中内部
MR1Bitアラーム内部
DM0Int32X軸 現在位置 (μm)データ
DM2Int32Y軸 現在位置 (μm)データ

KV-7000 の DM は Int32 を使う場合2ワード占有（DM0=下位ワード, DM1=上位ワード）。Int32 データ型を指定すると自動的に2ワード読み込みます。
chアドレスデータ型説明

R10Falling Edge—ハンド 真空切れ
リミットセンサーへの到達タイミングを記録し、動作範囲設定の確認に活用できます。
📋 Int32の位置データは2ワード占有のため、Project Builderで「Int32」型を指定するとアドレス+1も自動で読み込みます。
