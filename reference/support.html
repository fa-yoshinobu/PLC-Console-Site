Support

サポート

PLC IO Checker の問い合わせ先、問い合わせ前に確認する情報、Store 掲載用 URL のためのページです。

公開前確認

  • 正式なサポートメールアドレス、または問い合わせフォーム URL。
  • Store に表示する販売者名 / 開発者名と、このページに記載する表記の一致。
  • 対応言語。現時点の候補: 日本語、必要に応じて英語。
  • 返信目安、休業日、業務用途の緊急対応可否。
  • GitHub Issues を問い合わせ窓口として使うか、メールだけにするか。

問い合わせ前に確認する情報

通信、書込、QR、購入状態の問い合わせでは、次の情報があると確認が早くなります。設備情報を送る場合は、社外秘の IP アドレス、パスワード、設備名、顧客名を含めないようにしてください。

アプリ
Android / iOS、アプリバージョン、端末機種、OS バージョン。
PLC
メーカー、CPU機種、通信方式、ポート、接続先ネットワーク。
プロジェクト
接続種別、MELSEC / KEYENCE、問題が出るデバイス種別と address。

ProjectBuilder
使用バージョン、QR 生成条件、JSON読込時のエラー。

サポート範囲

PLC IO Checker の画面操作、プロジェクト読込、QR / JSON、対応 PLC、購入状態、アプリ内のエラー確認を対象にします。PLC 本体、ネットワーク機器、設備制御盤、現場安全手順の設計や変更は、設備管理者または PLC メーカーの資料に従ってください。

書込、CPU操作、トラップ、タイムチャート REC は実設備に影響する可能性があります。サポートへの問い合わせ前でも、現場の安全確認を優先してください。

公開 URL

このページは App Store Connect の Support URL、Google Play の Web site / support link の候補として使用できます。

公開前確認

GitHub Pages 公開後の URL を確定し、App Store Connect / Google Play Console の各入力欄へ同じ URL を登録します。独自ドメインを使う場合は、公開前に URL を差し替えます。
