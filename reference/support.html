サポート範囲

PLC IO Checker の画面操作、案件読込、QR / JSON、対応 PLC、購入状態、アプリ内のエラー確認を対象にします。PLC 本体、ネットワーク機器、設備制御盤、現場安全手順の設計や変更は、設備管理者または PLC メーカーの資料に従ってください。

書込、CPU 操作、Trap、Time Chart REC は実設備に影響する可能性があります。サポートへの問い合わせ前でも、現場の安全確認を優先してください。

公開 URL

このページは App Store Connect の Support URL、Google Play の Web site / support link の候補として使用できます。
