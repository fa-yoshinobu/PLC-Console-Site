Privacy Policy

プライバシーポリシー

FA Labo PLC Console は、ユーザーが設定した PLC へ接続するためにネットワーク通信を使用します。PLC データやプロジェクトデータを開発者サーバーへ送信しません。

最終更新日

2026-08-25

アプリで扱う情報

FA Labo PLC Console はユーザーアカウントを作成しません。アプリの通常利用において、氏名、住所、電話番号、メールアドレス、連絡先、写真、位置情報を開発者が自動的に収集する機能はありません。アプリ自体は、開発者のサーバーへ個人情報、PLC データ、プロジェクトデータを送信しません。

アプリ内の接続設定、プロジェクト、登録デバイス、タイムチャート、トラップ、コメント、履歴などは、ユーザーの端末内で利用されます。ユーザーが JSON、CSV、QR、画像などを保存または共有した場合、その保存先や共有先での扱いはユーザーが選択したサービスの規約に従います。

サポートへ問い合わせる場合、ユーザーが入力した氏名、メールアドレス、問い合わせ本文、アプリまたは ProjectBuilder のバージョン、端末・OS、PLC や接続環境に関する情報を、回答および不具合調査のために取り扱います。問い合わせフォームではファイルを収集しません。これらは対応と調査に必要な期間保持し、不要になった後に削除します。削除を希望する場合は、問い合わせフォームから依頼してください。

ネットワーク通信

Android 版は INTERNET と ACCESS_NETWORK_STATE permission を使用します。iOS 版は Local Network の説明を NSLocalNetworkUsageDescription に記載しています。これらは、ユーザーがアプリで設定した PLC の IP アドレス、ポート、通信方式に対して接続するために使用します。

FA Labo PLC Console は、ユーザーが設定した接続先以外へ PLC 監視値や書込値を送信する目的で通信しません。MELSEC / KEYENCE の読込、書込、コメント読込、CPU操作などの通信は、ユーザーが選択した PLC に対して行われます。

カメラと QR

Android / iOS 版は、ProjectBuilder に表示した QR コードからプロジェクト設定を取り込むためにカメラを使用します。カメラ画像や動画を保存したり、QR 画像または読み取った QR の内容を開発者サーバーへ送信したりする用途では使用しません。

Android 版の QR 読取には Google ML Kit Barcode Scanning SDK を使用します。同 SDK が診断および利用分析のために送信する情報については、「第三者サービス」を確認してください。Google の公式データ開示では、QR 画像および読み取った文字列自体は収集項目として記載されていません。

ファイルと端末内保存

Android 版は外部ストレージ全体へアクセスする permission を宣言していません。iOS 版も写真ライブラリや端末全体のファイルへ常時アクセスする権限は使用しません。

JSON、CSV、ログの読込・書出は、OS のファイル選択または保存ダイアログでユーザーが選んだファイルだけを対象にします。プロジェクト、設定、コメント、履歴は端末内のアプリ領域に保存されます。

権限の詳細は アプリ権限 を確認してください。

Android のバックアップと端末移行

Android 版は OS のバックアップ機能を有効にしています。Android 12 以降のクラウドバックアップでは、プロジェクト、アプリのセッションと履歴、実行中データ、プロジェクトコメント、PLC のリモートパスワードを対象外にしています。

Android 12 以降の端末間移行では、プロジェクト、アプリのセッションと履歴、実行中データ、プロジェクトコメントが OS による移行対象となる場合があります。PLC のリモートパスワードは端末間移行の対象外であり、移行後に必要に応じて再入力してください。Android 11 以前では、これらのプロジェクト関連データ、コメント、リモートパスワードをバックアップ対象外にしています。

実際にバックアップまたは移行されるかは、OS、端末メーカー、ユーザーのバックアップ設定および利用する移行方法によって異なります。詳しくは Android のバックアップに関する説明を確認してください。

タイムチャート記録

Android 版はタイムチャート記録中にバックグラウンドへ移った場合、foreground service の通知を表示して記録を継続します。これは端末内での記録継続のためであり、PLC データを開発者サーバーへ同期する用途ではありません。

第三者サービス

FA Labo PLC Console は、広告配信またはユーザーを横断的に追跡する目的の第三者サービスを使用しません。

問い合わせフォーム（Formspree）

Webサイトの問い合わせフォームには Formspree, Inc. が提供する Formspree を使用します。フォームへ入力して送信した情報は、問い合わせの受付、迷惑送信の判定、通知および回答のために Formspree へ送信され、Formspree のサーバーと FA Labo の通知先メールボックスに保存されます。

送信時には、入力内容に加えて IP アドレス、ブラウザの種類、アクセス日時、参照元Webサイトなどが Formspree により取得される場合があります。情報は米国その他の Formspree がサービスを運営する国で処理される場合があります。詳しくは Formspree Privacy Policy を確認してください。

問い合わせフォームは Formspree の迷惑送信対策を使用します。対策の判定により CAPTCHA が表示される場合があります。フォームを送信しない限り、FA Labo はフォームの入力内容を取得しません。

Android QR 読取（Google ML Kit）

Android 版は QR 読取のために Google ML Kit Barcode Scanning SDK を使用します。Google の公式データ開示によると、ML Kit Android SDK は、診断および利用分析のために次の情報を収集します。

  • 端末のメーカー、モデル、OS バージョン、ビルド、利用可能な機械学習用ハードウェアなどの端末情報
  • パッケージ名、アプリバージョンなどのアプリ情報
  • ユーザーや物理端末を一意に識別することを目的としない、インストールごとの識別子
  • 処理時間などの性能情報、画像形式や解像度などの API 設定、入出力サイズ、機能バージョン
  • 初期化、検出、リソース解放などのイベント種別とエラーコード

これらの情報は HTTPS で暗号化して Google へ送信され、Google の開示では第三者へ移転しないとされています。送信先は Google であり、FA Labo の開発者サーバーではありません。Android 版は ML Kit の自動ズーム機能を使用していません。

アプリ内購入やストア配布に関する処理は Apple App Store または Google Play によって行われます。FA Labo PLC Console はクレジットカード番号などの支払情報を取得しません。

保存期間と削除

FA Labo PLC Console はユーザーアカウントを作成しません。開発者サーバーにアプリから個人情報、PLC データ、プロジェクトデータを保存しないため、サーバー側のアカウント削除手続きはありません。サポート問い合わせの送信履歴は Formspree で利用中のプランに定められた期間保存されます。FA Labo の通知先メールボックスでは、対応と調査に必要な期間保持し、不要になった後に削除します。削除については、問い合わせフォームから依頼してください。

端末内に保存されたプロジェクト、設定、履歴は、ユーザーがアプリ内操作、OS のアプリデータ削除、またはアプリのアンインストールによって削除できます。ユーザーが外部へ保存または共有した JSON、CSV、QR、画像は、保存先や共有先で管理してください。

ProjectBuilder

PLC Console ProjectBuilder は、PC 上で FA Labo PLC Console 用のプロジェクトJSONと QR を作成するためのツールです。作成したファイル、QR、画像はユーザーが管理します。ProjectBuilder も個人情報を開発者のサーバーへ送信する用途では使用しません。

お問い合わせ

本ポリシーに関する問い合わせは、問い合わせフォームを利用してください。

English Summary

FA Labo PLC Console uses network access to connect to PLCs configured by the user. Camera access is used only for QR import. File import/export is limited to files selected by the user through the operating system. The app does not send personal data, PLC data, project data, QR images, or decoded QR content to FA Labo developer servers. The Android app uses Google ML Kit Barcode Scanning. According to Google, the SDK sends device and app information, per-installation identifiers, performance and API metrics, event types, and error codes to Google over HTTPS for diagnostics and usage analytics. The website contact form is processed by Formspree. Information voluntarily submitted for support is used to respond and investigate issues, retained only as long as needed, and then deleted.
