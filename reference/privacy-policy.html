Privacy Policy

プライバシーポリシー

FA Labo PLC Console は、ユーザーが設定した PLC へ接続するためにネットワーク通信を使用します。PLC データやプロジェクトデータを開発者サーバーへ送信しません。

最終更新日

2026-08-25

取り扱う情報

FA Labo PLC Console はユーザーアカウントを作成しません。アプリの通常利用において、氏名、住所、電話番号、メールアドレス、連絡先、写真、位置情報を FA Labo が自動的に収集する機能はありません。

接続設定、プロジェクト、登録デバイス、タイムチャート、トラップ、コメント、履歴などは端末内で利用されます。JSON、CSV、QR、画像などを保存または共有した場合は、ユーザーが選択した保存先または共有先の規約に従って取り扱われます。

サポートへ問い合わせる場合、名前またはハンドルネーム、メールアドレス、問い合わせ内容、アプリまたは ProjectBuilder のバージョン、端末・OS、PLC 型式など、ユーザーが入力した情報を回答および不具合調査のために利用します。問い合わせフォームではファイルを収集しません。不具合解析に必要な場合は、返信時に案内したメールアドレスへユーザーが任意に送付したログデータや画像も同じ目的で利用します。

ネットワーク、カメラ、ファイル

ネットワーク通信は、ユーザーが設定した PLC への読込、書込、コメント読込、CPU操作などに使用します。

カメラは、ProjectBuilder に表示した QR コードからプロジェクト設定を取り込むために使用します。カメラ画像や動画は保存せず、読み取った内容は端末内でプロジェクトの取込みに使用します。

JSON、CSV、ログの読込・書出は、OS のファイル選択または保存画面でユーザーが選んだファイルだけを対象にします。カメラやローカルネットワークなどの権限は、OS の設定から変更できます。詳しくは アプリ権限を確認してください。

第三者サービス

FA Labo PLC Console は、広告配信またはアプリを横断してユーザーを追跡する目的のサービスを使用しません。第三者サービスについては、各社の規約とプライバシーポリシーを確認し、本ポリシーおよび適用法令と同等の保護が確保されるサービスを利用します。

Android QR 読取（Google ML Kit）

Android 版の QR 読取には Google ML Kit Barcode Scanning SDK を使用します。Google の公式データ開示によると、同 SDK は診断および利用分析のため、端末・アプリ情報、インストールごとの識別子、性能情報、API 設定、イベント種別、エラーコードなどを HTTPS で Google へ送信します。QR 画像および読み取った文字列は収集項目として記載されていません。Android 版は ML Kit の自動ズーム機能を使用していません。

アプリ内購入

購入処理は Apple App Store または Google Play を通じて行われます。アプリは、利用権を確認するために商品情報、購入状態、取引情報を取得しますが、クレジットカード番号などの支払情報は取得しません。

問い合わせフォーム（Formspree）

問い合わせフォームには Formspree, Inc. が提供する Formspree を使用します。送信された内容は、問い合わせの受付、迷惑送信の判定、通知および回答のため、Formspree と FA Labo の通知先メールボックスに保存されます。送信時には、IP アドレス、ブラウザの種類、アクセス日時、参照元Webサイトなどが Formspree により取得される場合があります。情報は米国その他の Formspree がサービスを運営する国で処理される場合があります。詳しくは Formspree Privacy Policyを確認してください。

迷惑送信対策の判定により CAPTCHA が表示される場合があります。フォームを送信しない限り、FA Labo はフォームの入力内容を取得しません。

Webサイト（GitHub Pages）

本Webサイトは GitHub Pages を利用して配信しています。閲覧時には、GitHub がセキュリティ目的で訪問者の IP アドレスを記録します。詳しくは GitHub Privacy Statementを確認してください。

端末内保存、バックアップ、削除

プロジェクト、設定、コメント、履歴は端末内のアプリ領域に保存されます。Android 版では、プロジェクト関連データ、コメント、PLC のリモートパスワードをクラウドバックアップの対象外にしています。端末間移行では、リモートパスワードを除くプロジェクト関連データが移行される場合があります。iOS 版では、プロジェクト関連データとコメントをバックアップの対象外にし、リモートパスワードを端末に限定した Keychain に保存します。実際のバックアップと端末移行は、OS、端末およびユーザーの設定によって異なります。

端末内データは、アプリ内の削除操作または OS のアプリデータ削除機能で削除できます。iOS の Keychain に保存したリモートパスワードは、アプリのアンインストールだけでは削除されない場合があるため、アプリ内の削除操作を利用してください。外部へ保存または共有した JSON、CSV、QR、画像は、保存先または共有先で削除してください。

保存期間と削除依頼

問い合わせ情報は、回答、不具合調査、法令遵守および紛争対応に必要な期間保存します。問い合わせ情報の削除を希望する場合は、問い合わせフォームから依頼できます。ただし、法令遵守または紛争対応のため保存が必要な情報を除きます。

FA Labo PLC Console はユーザーアカウントを作成しないため、アカウント削除の手続きはありません。

ProjectBuilder

PLC Console ProjectBuilder は、PC 上でプロジェクトJSONと QR を作成します。作成したファイル、QR、画像はユーザーが管理し、ProjectBuilder から個人情報やプロジェクトデータを FA Labo のサーバーへ送信しません。

お問い合わせ

個人情報の取扱いに関する問い合わせ、保有個人データの開示、訂正、利用停止、削除等の請求は、問い合わせフォームから受け付けます。本人確認をお願いする場合があります。事業者の氏名・住所その他の法令上の公表事項は、本人の求めに応じて回答します。

English Summary

FA Labo PLC Console does not create user accounts or send personal data, PLC data, or project data to FA Labo servers. Project data is stored on the device. Network access is used for PLC communication, camera access is used for QR import, and file access is limited to files selected by the user. The Android app uses Google ML Kit Barcode Scanning, which sends diagnostic and usage data described by Google to Google. In-app purchases are processed through Apple App Store or Google Play. The contact form is processed by Formspree, and this website is hosted on GitHub Pages. Support information is retained only as needed for responses, investigations, legal compliance, and dispute resolution. Requests regarding access, correction, restriction, or deletion can be submitted through the contact form.
