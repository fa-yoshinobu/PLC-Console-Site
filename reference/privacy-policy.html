Privacy Policy

プライバシーポリシー

PLC IO Checker は、ユーザーが設定した PLC へ接続するためにネットワーク通信を使用します。個人情報の収集は行いません。

公開前確認

  • Store に表示する開発者名 / 販売者名と、このページの表記を一致させる。
  • 正式な privacy point of contact を記載する。
  • 最終更新日を記載する。
  • アプリ内からこのページを開ける導線を確認する。

収集する情報

PLC IO Checker は、氏名、住所、電話番号、メールアドレス、連絡先、写真、位置情報などの個人情報を収集しません。開発者のサーバーへ個人情報、PLC データ、プロジェクトデータを送信しません。

アプリ内の接続設定、プロジェクト、登録デバイス、タイムチャート、トラップ、コメント、履歴などは、ユーザーの端末内で利用されます。ユーザーが JSON、CSV、QR、画像などを保存または共有した場合、その保存先や共有先での扱いはユーザーが選択したサービスの規約に従います。

ネットワーク通信

Android 版は INTERNET と ACCESS_NETWORK_STATE permission を使用します。iOS 版は Local Network の説明を NSLocalNetworkUsageDescription に記載しています。これらは、ユーザーがアプリで設定した PLC の IP アドレス、ポート、通信方式に対して接続するために使用します。

PLC IO Checker は、ユーザーが設定した接続先以外へ PLC 監視値や書込値を送信する目的で通信しません。MELSEC / KEYENCE の読込、書込、コメント読込、CPU操作などの通信は、ユーザーが選択した PLC に対して行われます。

カメラと QR

Android / iOS 版は、ProjectBuilder に表示した QR コードからプロジェクト設定を取り込むためにカメラを使用します。カメラ画像や動画を保存したり、開発者サーバーへ送信したりする用途では使用しません。

ファイルと端末内保存

Android 版は外部ストレージ全体へアクセスする permission を宣言していません。iOS 版も写真ライブラリや端末全体のファイルへ常時アクセスする権限は使用しません。

JSON、CSV、ログの読込・書出は、OS のファイル選択または保存ダイアログでユーザーが選んだファイルだけを対象にします。プロジェクト、設定、コメント、履歴は端末内のアプリ領域に保存されます。

権限の詳細は アプリ権限 を確認してください。

タイムチャート記録

Android 版はタイムチャートの REC 中にバックグラウンドへ移った場合、foreground service の通知を表示して記録を継続します。これは端末内での記録継続のためであり、PLC データを開発者サーバーへ同期する用途ではありません。

第三者サービス

PLC IO Checker は、広告配信、トラッキング、解析 SDK による個人情報収集を目的とした第三者サービスを使用しません。

アプリ内購入やストア配布に関する処理は Apple App Store または Google Play によって行われます。PLC IO Checker はクレジットカード番号などの支払情報を取得しません。

保存期間と削除

PLC IO Checker はユーザーアカウントを作成しません。開発者サーバーに個人情報、PLC データ、プロジェクトデータを保存しないため、サーバー側のアカウント削除手続きはありません。

端末内に保存されたプロジェクト、設定、履歴は、ユーザーがアプリ内操作、OS のアプリデータ削除、またはアプリのアンインストールによって削除できます。ユーザーが外部へ保存または共有した JSON、CSV、QR、画像は、保存先や共有先で管理してください。

ProjectBuilder

PlcIoChecker_ProjectBuilder は、PC 上で PLC IO Checker 用のプロジェクトJSONと QR を作成するためのツールです。作成したファイル、QR、画像はユーザーが管理します。ProjectBuilder も個人情報を開発者のサーバーへ送信する用途では使用しません。

お問い合わせ

本ポリシーに関する問い合わせは、配布ページに記載された連絡先、または GitHub: fa-yoshinobu から行ってください。

English Summary

PLC IO Checker uses network access only to connect to PLCs configured by the user. Camera access is used only for QR import. File import/export is limited to files selected by the user through the operating system. The app does not collect personal data, does not send PLC data or project data to developer servers, and does not use advertising, tracking, or analytics services for personal data collection.
