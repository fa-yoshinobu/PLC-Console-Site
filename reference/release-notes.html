Release Notes

リリースノート

FA Labo PLC Console のバージョンごとの主な機能、変更点、利用上の注意を案内します。

1.0.0 — 初回公開版

バージョン
1.0.0
対象
FA Labo PLC Console（Android / iOS）
対応環境
iOS / iPadOS 18 以降、Android 10 以降。

主な機能

  • MELSEC、KEYENCE PLC への TCP / UDP 接続と、接続設定の到達確認。
  • ブロック、リスト、タイムチャート、トラップによるデバイス監視。
  • BIT・数値デバイスへの書込、書込ロック、CPU の RUN / STOP / PROGRAM 操作。
  • デバイスコメント読込、CSV コメント読込、エラー履歴の表示。
  • QR / JSON によるプロジェクトの読込・書出と、Windows 用 ProjectBuilder との連携。
  • PLC と購入がなくても監視画面や値変化を確認できる MELSEC / KEYENCE Demo。
  • MELSEC / KEYENCE メーカー別の実機通信ライセンスと購入状態の復元。
  • 日本語、英語の表示切替。

実設備で使用する前に

書込、CPU操作、トラップ、タイムチャート記録は実設備に影響する可能性があります。対象 PLC、接続先、設備状態を確認し、現場の安全手順と設備管理者の指示に従ってください。

配布状況、公開日、提供地域は App Store または Google Play に表示される情報を正とします。購入条件は購入・返金案内を確認してください。
