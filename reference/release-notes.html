Release Notes

リリースノート

PLC IO Checker アプリケーションの公開バージョンごとの変更点、注意点、既知の制限を記録するページです。

First release

Version
正式公開時に記載します。
Release date
正式公開時に記載します。
Target
PLC IO Checker Android / PLC IO Checker iOS
Summary
MELSEC / KEYENCE の接続、監視、書込、記録、QR/JSON 連携を扱う初回公開。
Notes
ストア URL、購入状態、PLC 側設定参考の詳細は正式公開または実機確認後に追記します。

記載する項目

Version
公開した PLC IO Checker アプリのバージョン。
Release date
正式に公開した日付。未公開の予定日は書きません。
Target
Android、iOS、または両方のどれに関係する変更か。
Added
追加された機能や対応 PLC。
Changed
操作、表示、通信、QR/JSON、設定などの変更点。
Fixed
修正された不具合。
Known limitations
公開時点で残る制限や注意点。

更新ルール

  • アプリのソースコード、リリースタグ、配布物、ストア公開状態を確認してから詳細化します。
  • 未実装の予定機能や、公開していない変更は書きません。
  • MELSEC / KEYENCE、Android / iOS で影響範囲が違う場合は分けて書きます。
  • ProjectBuilder の変更履歴はこのページには書きません。exe は PlcIoChecker_ProjectBuilder Releases の Assets にある PlcIoCheckerProjectBuilder-win-x64.zip からダウンロードします。
  • 書込、CPU操作、通信、QR/JSON に関わる変更は、必要な注意点も一緒に書きます。
