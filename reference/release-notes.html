初回公開に含まれる主な機能

対応 PLC

MELSEC（三菱電機）
iQ-F / iQ-L / iQ-R / Q / L シリーズ（SLMP TCP/UDP）
KEYENCE
KV-5000 / KV-7000 / KV-8000 / KV-X500 / KV-XLE02（HostLink）

監視・記録

  • List 監視 / Block 監視
  • 操作パネル（フォーカスパネル）: 値の拡大表示、書込、トレンド
  • タイムチャート記録: 最大 20 チャンネル、1,000 サンプル（約 500 秒）、CSV 書出
  • トラップ: 最大 20 件の条件登録、イベント履歴 CSV 書出
  • デバイスコメント: PLC からの読込、CSV 一括読込
  • CPU 操作: RUN/STOP（MELSEC のみ）

プロジェクト管理

  • プロジェクト JSON による設定の保存・読込
  • ProjectBuilder との QR コード連携
  • Android / iOS 間でのプロジェクト JSON 互換

その他

  • Demo モード: 実機 PLC なしで動作確認できます（値変化パターン選択可）
  • Android / iOS 対応

既知の制限

  • アプリを終了するとタイムチャートのバッファとトラップイベント履歴は消去されます。
  • iOS はバックグラウンドへ移行するとポーリングが停止します（タイムチャート記録中も同様）。
  • SLMP / HostLink は工場内の閉域ネットワーク向けプロトコルであり、通信は暗号化されません。
