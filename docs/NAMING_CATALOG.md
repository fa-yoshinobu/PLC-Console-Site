# 名称台帳

FA Labo PLC Console の画面名以外の呼び方を揃えるための保守メモです。公開マニュアル、アプリ表示、リリースノート、ストア説明、GitHub の作業メモで表記を合わせる目的で使います。

画面、パネル、シート、ダイアログの名前は [`WINDOW_NAMES.md`](./WINDOW_NAMES.md) で管理します。

## 命名ルール

| 種別 | 方針 |
| --- | --- |
| 機能名 | メニューやボタンに出る短い名称を正とする。説明文では補足してよい。 |
| 操作名 | ユーザーが実際に押す/選ぶ文言に寄せる。内部処理名は出さない。 |
| 表示モード名 | アプリ画面に表示される名称を使い、内部設定名を公開ページに出さない。 |
| データ名 | ファイル形式、登録対象、記録対象を区別する。 |
| 英語名 | アプリ英語表示、または説明用の短い英語名に揃える。無理に直訳しない。 |

## 主要機能名

| 正式名 | 英語名 | 使う場所 | 避ける表記 / 注意 |
| --- | --- | --- | --- |
| 接続先切替 | Connection Switch | ヘッダー接続情報、説明文 | `プロジェクト切り替え` だけにしない。接続とプロジェクトの入口を兼ねる。 |
| 通信設定 | Connection Settings | 接続設定画面、メニュー説明 | `PLC設定` は内部/短縮表示として扱う。公開説明は `通信設定` を優先。 |
| CPU操作 | CPU Operation | メニュー、CPU操作説明 | `RUN/STOP画面` とは呼ばない。 |
| List 登録編集 | List Registration Edit | List 編集入口、説明文 | `デバイス編集`、`リスト編集` だけにしない。 |
| デバイス範囲 | Device Ranges | メニュー、監視説明 | `レンジ` だけにしない。 |
| モニタ表示設定 | Monitor Display Settings | Block 表示設定 | `Block/List表示設定`、`表示設定` だけにしない。 |
| コメント読込 | Comment Read | PLC からコメントを読む機能 | `コメント取得` と混ぜない。 |
| CSVコメント読込 | CSV Comment Import | CSV ファイルからコメントを読む機能 | `CSV読込` だけだとタイムチャートCSVと混ざる。 |
| QR読込 | QR Import | ProjectBuilder QR の読込 | `QRインポート` ではなくアプリ表示に合わせる。 |
| JSON読込 | JSON Import | プロジェクトJSONの読込 | `プロジェクト読込` だけにしない。 |
| JSON書出 | JSON Export | プロジェクトJSONの書出 | `バックアップ` とは呼ばない。 |
| エラー履歴 | Error History | エラー確認と保存 | `ログ` と混ぜない。 |
| アプリ設定 | App Settings | アプリ全体の設定 | `設定` だけだと通信設定と混ざる。 |
| ライセンス/購入 | License / Purchase | 実機通信ライセンス | `課金` だけで説明しない。 |
| バージョン情報 | Version Info | バージョン表示 | `About` は英語UIや内部だけ。 |

## タブ・表示領域

| 正式名 | 英語名 | 使う場所 | 避ける表記 / 注意 |
| --- | --- | --- | --- |
| List / リスト | List | 登録デバイス一覧 | 公開ページでは `List` を優先し、必要なら `リスト` を併記。 |
| Block / ブロック | Block | デバイス範囲表示 | メニューの `block` とは書かず、文中は `Block` または `ブロック`。 |
| タイムチャート | Time Chart | 波形記録 | Android内部の `Log`、`ログ` は公開名にしない。 |
| トラップ | Trap | 条件検知 | `Trap settings` は英語UI/内部寄り。日本語は `トラップ`。 |
| デバイス操作パネル | Device Control Panel | 選択デバイスの操作領域 | `フォーカスパネル`、`ON/OFFパネル` は避ける。 |
| ヘッダー / ステータスライン | Header / Status Line | 上部状態表示 | `上のバー` など曖昧な呼び方は避ける。 |

| グラフ100%値 | Graph 100% Value | Block の数値バー基準 | `ワードバー上限値` は内部寄り。公開名はこれ。 |
| 画面配置 | Screen Layout | アプリ設定 | `レイアウト` だけにしない。 |

## 操作名・ボタン名

| 正式名 | 英語名 | 対象 | 避ける表記 / 注意 |
| --- | --- | --- | --- |
| 接続 / 切断 | Connect / Disconnect | PLC 通信 | `ON/OFF` と混ぜない。 |
| RUN / STOP | RUN / STOP | MELSEC CPU 操作 | KEYENCE 停止側は `PROGRAM`。 |

| ON/OFF操作 | ON/OFF Control | BIT 書込 | パネル名ではない。 |
| 現在値 | Current Value | デバイス値表示 | カーソル時の値とは分ける。 |
| カーソル値 | Cursor Value | タイムチャート | タイムチャートのカーソル位置の値。 |

| REC | REC | タイムチャート記録 | ボタン表示は `REC`。説明では `記録開始/停止` と補足可。 |

## データ・登録対象

| 正式名 | 英語名 | 意味 | 避ける表記 / 注意 |
| --- | --- | --- | --- |
| プロジェクト | Project | PLC 接続設定、登録デバイス、タイムチャート、トラップなどの設定単位 | `設定ファイル` だけにしない。 |
| プロジェクトJSON | Project JSON | プロジェクトの読込/書出ファイル | `JSON` だけだと形式一般になる。 |
| List 登録 | List Registration | List に表示する登録デバイス | タイムチャート登録、トラップ登録とは別。 |
| タイムチャート登録 | Time Chart Registration | タイムチャートで監視するチャンネル登録 | List 登録と連動しない前提で説明する。 |
| トラップ登録 | Trap Registration | 検知条件の登録 | List 登録、タイムチャート登録とは別。 |
| デバイスコメント | Device Comment | PLC デバイスに付ける表示用コメント | `コメント` だけでも可だが、初出は `デバイスコメント`。 |
| 一時コメント | Temporary Comment | PLC/CSV から読み込んだ表示用コメント | 公開ページでは通常出さない。 |
| エラー履歴 | Error History | アプリが保存するエラー一覧 | 通信ログや波形ログとは分ける。 |
| タイムチャート履歴 | Time Chart History | 波形記録バッファ | `ログ` と呼ばない。 |
| トラップイベント | Trap Event | トラップ検知履歴の1件 | `トラップ履歴` と説明してもよい。 |

## PLC・デバイス用語

| 正式名 | 英語名 | 意味 | 避ける表記 / 注意 |
| --- | --- | --- | --- |
| PLC | PLC | 制御機器全般 | メーカー名と混ぜない。 |
| MELSEC | MELSEC | 三菱電機 PLC 系統 | `三菱` だけにしない。 |
| KEYENCE | KEYENCE | キーエンス PLC 系統 | `KV` だけにしない。 |
| CPU機種 | CPU Model | 接続先 PLC のCPU/ユニット機種 | `機種` だけだと端末機種と混ざる。 |
| デバイス | Device | PLC のアドレス単位 | スマートフォン端末の意味では使わない。 |
| アドレス | Address | 例: `X0`、`D100`、`DM100` | `番地` は説明補助に留める。 |
| BIT | BIT | ON/OFF の 1 bit 値 | `ビットデバイス` と説明してもよい。 |
| WORD | WORD | 数値として扱う領域 | `ワード` は補足可。 |
| データタイプ | Data Type | `Int16`、`UInt16`、`Int32`、`UInt32`、`Float32` | `表示型` と関係するが完全同義にはしない。 |
| SLMP | SLMP | MELSEC の通信方式 | 初出だけ `Seamless Message Protocol` を補足可。 |
| Host-link | Host-link | KEYENCE の上位リンク通信 | `HostLink` 表記と混在させない。 |

| 正式名 | 英語名 | 対象 | 避ける表記 / 注意 |
| --- | --- | --- | --- |
| 接続中 | Connected | PLC 接続状態 | `通信中` と混ぜる場合は文脈を明確にする。 |
| 未接続 | Disconnected | PLC 接続状態 | `オフライン` は説明補助に留める。 |

## 表記注意

| 避ける表記 | 使う表記 | 理由 |
| --- | --- | --- |
| フォーカスパネル | デバイス操作パネル | `FocusPanel` は内部名。 |
| ON/OFFパネル | デバイス操作パネル / ON/OFF操作 | パネル全体とBIT操作を分ける。 |
| ログ画面 | タイムチャート | Android内部の `ViewMode.Log` と公開名を混ぜない。 |
| ワードバー上限値 | グラフ100%値 | ユーザーには数値バー/グラフの基準値として見える。 |
| CSV読込 | CSVコメント読込 | 何のCSVかを明確にする。 |
| デバイス編集 | List 登録編集 | 何の登録を編集するか分かる名称にする。 |
| 設定 | 通信設定 / アプリ設定 / モニタ表示設定 | 入口ごとの目的を分ける。 |
