Install

入手・インストール

Android / iOS アプリと PC 用 ProjectBuilder の入手先をまとめます。

配布状況

モバイルアプリの一般配布は現在開始していません。Windows 用 ProjectBuilder は GitHub Releases から入手できます。

動作環境

iOS / iPadOS
iOS 18 以降の iPhone、iPadOS 18 以降の iPad。
Android
Android 10 以降を搭載し、Google Play に対応するスマートフォンまたはタブレット。
実機 PLC 通信
端末から接続先 PLC へ到達できる Wi-Fi または有線 LAN 環境が必要です。
Demo
PLC、ネットワーク接続、アプリ内購入なしで利用できます。
ProjectBuilder
Windows / .NET 8 / WPF。

モバイルアプリ

Android

一般配布開始後は、Google Play で FA Labo PLC Console と提供元を確認してインストールします。

iOS

一般配布開始後は、App Store で FA Labo PLC Console と提供元を確認してインストールします。

確認

同名または類似名のアプリと区別するため、アプリ名だけでなくアイコンと提供元も確認してください。

ProjectBuilder

PC でプロジェクトを作成し、QR または JSON でモバイルアプリへ渡す Windows WPF アプリです。exe は GitHub Releases の Assets にある PlcIoCheckerProjectBuilder-win-x64.zip からダウンロードします。

対象
Windows / .NET 8 / WPF
起動ファイル
PlcIoCheckerProjectBuilder.exe
主な用途
PLC 設定、デバイス、タイムチャート、トラップ、QR/JSON 出力
ダウンロード
PLC-Console-ProjectBuilder Releases の Assets から PlcIoCheckerProjectBuilder-win-x64.zip を選びます。
ソース
