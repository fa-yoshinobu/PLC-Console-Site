入手・インストール

Android / iOS アプリと PC 用 ProjectBuilder の入手先をまとめます。

公開状況

App Store / Google Play のストアリンクは、正式公開後にこのページへ掲載します。ProjectBuilder は GitHub Releases から入手できます。

対象

Android / iOS の PLC IO Checker と、Windows WPF 版の PlcIoChecker_ProjectBuilder が対象です。

モバイルアプリ

Android

Google Play の公開ページからインストールします。

正式公開後に URL を掲載します。

iOS

App Store の公開ページからインストールします。

正式公開後に URL を掲載します。

注意

ストアリンクが未掲載の間は、公開前または掲載準備中です。購入可能な公式リンクだけをこのページに掲載します。

ProjectBuilder

PC でプロジェクトを作成し、QR または JSON でモバイルアプリへ渡す Windows WPF アプリです。exe は GitHub Releases の Assets にある PlcIoCheckerProjectBuilder-win-x64.zip からダウンロードします。

対象
Windows / .NET 8 / WPF
起動ファイル
PlcIoCheckerProjectBuilder.exe
主な用途
PLC 設定、デバイス、タイムチャート、トラップ、QR/JSON 出力
ダウンロード
PlcIoChecker_ProjectBuilder Releases の Assets から PlcIoCheckerProjectBuilder-win-x64.zip を選びます。
ソース
PlcIoChecker_ProjectBuilder
