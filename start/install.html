入手・インストール

Android / iOS アプリと PC 用 ProjectBuilder の入手先をまとめます。ストア URL は正式公開前のため dummy link です。

対象

Android / iOS の PLC IO Checker と、Windows WPF 版の PlcIoChecker_ProjectBuilder が対象です。

モバイルアプリ

Android

Google Play 公開 URL が確定するまでは dummy link を使用します。

Google Play dummy link

iOS

App Store 公開 URL が確定するまでは dummy link を使用します。

App Store dummy link

注意

dummy link は公開済み・購入可能という意味ではありません。正式 URL に差し替えるまでは案内用の仮リンクです。

ProjectBuilder

PC でプロジェクトを作成し、QR または JSON でモバイルアプリへ案件として渡す Windows WPF アプリです。exe は GitHub Releases の Assets にある PlcIoCheckerProjectBuilder-win-x64.zip からダウンロードします。

対象
Windows / .NET 8 / WPF
起動ファイル
PlcIoCheckerProjectBuilder.exe
主な用途
PLC 設定、デバイス、タイムチャート、トラップ、QR/JSON 出力
ダウンロード
PlcIoChecker_ProjectBuilder Releases の Assets から PlcIoCheckerProjectBuilder-win-x64.zip を選びます。
ソース
