トップ対応 PLC

Supported PLC

対応 PLC

アプリと ProjectBuilder で選択できる PLC 種別、CPU model、既定ポート、通信方式です。

MELSEC

CPU model
iQ-R、iQ-F、iQ-L、MX-R、MX-F、QnUDV、QnU、QCPU、LCPU
通信方式
SLMP
既定ポート
1025
通信
TCP または UDP を PLC 側設定に合わせます。
MELSEC専用項目
network、station、module_io、multidrop、リモートパスワード

KEYENCE

CPU model
KV-X500、KV-8000、KV-7000、KV-5000
通信方式
KV Host Link
既定ポート
8501
デバイス表記
Normal または XYM
使用しない項目
MELSEC の route 指定とリモートパスワードは KEYENCE では使いません。

実機接続の注意

実機通信は PLC 側の Ethernet 設定、ポート、通信許可、ネットワーク経路が合っている必要があります。接続前に対象 PLC と IP アドレスを確認してください。
