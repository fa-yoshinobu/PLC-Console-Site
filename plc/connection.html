Connection

接続・案件

接続先切替、案件作成、通信設定、実機/デモの選択を説明します。

接続先切替を開く

上部タイトル部分をタップすると接続先切替を開けます。通信設定はハンバーガーメニューではなく、このタイトル導線から開きます。

  • 現在の接続内容を確認できます。
  • MELSEC 実機、KEYENCE 実機、MELSEC デモ、KEYENCE デモを選べます。
  • 最近使った案件から再選択できます。

通信設定で確認する項目

PLC 種別
MELSEC または KEYENCE を選択します。
CPU / Family
対象 PLC の CPU ファミリを選択します。
IP / Port
PLC 側の Ethernet 設定に合わせます。
Transport
TCP または UDP を選択します。
Route
必要な場合だけ network、station、module_io、multidrop を指定します。

MELSEC の設定

通信方式

SLMP で接続します。既定ポートは 1025 です。PLC 側の設定に合わせて TCP または UDP を選びます。

CPU モデル

iQ-R、iQ-F、iQ-L、MX-R、MX-F、QnUDV、QnU、QCPU、LCPU から選びます。

ルート / パスワード

network、station、module_io、multidrop とリモートパスワードは MELSEC 用です。

KEYENCE の設定

通信方式

KV Host Link で接続します。既定ポートは 8501 です。

対応モデル

KV-X500、KV-8000、KV-7000、KV-5000 から選びます。

KEYENCE 表示

Normal または XYM を選びます。XYM は X/Y/M/L/D/E/F 系の表記を使う場合のモードです。

KEYENCE では MELSEC 用の network/station/module_io/multidrop とリモートパスワードは使用しません。

接続結果の見方

  • 接続成功時は上部ステータスに RUN/STOP、CPU、IP、案件名が表示されます。
  • 未処理の CPU 状態は -- と表示されます。
  • MELSEC で接続できない場合は、IP、ポート、TCP/UDP、ルート指定、リモートパスワード、PLC 側の通信許可を確認してください。
  • KEYENCE で接続できない場合は、IP、ポート、KV Host Link、KEYENCE 表示モード、端末のネットワーク接続を確認してください。
