接続・プロジェクト

接続先切替、プロジェクト選択、上部ステータスの確認方法を説明します。

接続先を選ぶ

初回は はじめかた が表示されます。接続する PLC メーカー、または操作を確認する Demo を選びます。通常は前回の接続先から再開します。

  • MELSEC を使う / KEYENCE を使う：実機の通信設定を開きます。
  • MELSEC デモ / KEYENCE デモ：デモプロジェクトを開きます。
  • 接続先を変更するときは、上部ステータス部分をタップします。

上部ステータスの見方

表示内容
RUN/STOP/PROGRAM / CPU機種 / IP / プロジェクト名。
状態表示
CPU 状態は RUN、STOP、PROGRAM の文字で確認します。
接続ボタン
接続中 または 未接続 の 2 状態で表示します。デモの場合はボタン内に DEMO が表示されます。
書込ロック
ロック / 解除 で、出力や値の書込が許可されているかを示します。
