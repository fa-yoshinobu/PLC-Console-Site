共通で確認する項目

IP address
アプリの接続設定と PLC 側 Ethernet 設定を合わせます。
Port
MELSEC は既定 1025、KEYENCE は既定 8501 です。実際の PLC 側設定に合わせます。
Protocol
MELSEC は SLMP、KEYENCE は KV Host Link TCP を前提にしています。
Access permission
PLC 側で外部機器からの通信や書込が許可されているか確認します。詳細手順は TODO です。
