MELSEC

MELSEC 設定

MELSEC で使う接続設定と表記ルールです。

開き方と確認内容

  1. 開く上部ステータス部分をタップして 接続先切替 を開き、MELSEC の接続先を選びます。
  2. 確認接続設定 で IP、Port、機種、通信、ルーティング、タイミングを確認します。
  3. 接続後上部ステータスに RUN/STOP、CPU機種、IP、プロジェクト名が表示されます。

接続設定

通信方式
SLMP（Seamless Message Protocol）
PLC IP / Port
PLC 側の Ethernet 設定に合わせます。既定ポートは 1025 です。
通信
TCP / UDP
機種
MELSEC iQ-R (built-in)、MELSEC iQ-R (RJ71EN71)、MELSEC iQ-F (built-in)、MELSEC iQ-L (built-in)、MELSEC MX-R (built-in)、MELSEC MX-F (built-in)、MELSEC QnUDV (built-in)、MELSEC QnUDV (QJ71E71-100)、MELSEC QnU (built-in)、MELSEC QnU (QJ71E71-100)、MELSEC-Q (QJ71E71-100)、MELSEC-L (built-in)、MELSEC-L (LJ71E71-100)。(built-in) は内蔵 Ethernet ポート、ユニット名付きは Ethernet ユニット経由の接続です。
リモートパスワード
PLC 側で設定している場合に入力します。使用していない場合は空欄にします。
到達確認
入力した接続設定で確認を実行し、結果とエラーメッセージを確認します。

PLC 側の Ethernet 設定、通信許可、リモートパスワードは 接続設定例 で確認します。

ルーティング

ネットワーク
ネットワーク経由で他局に接続したい場合、ネットワークの番号を指定します。自局CPUに接続する場合は、0を指定してください。
局番
ネットワーク経由で他局に接続したい場合、子局の番号を指定します。自局CPUに接続する場合は、255を指定してください。
ユニットI/O
接続先に合わせて 自局、制御系CPU、待機系CPU、A系CPU、B系CPU、マルチCPU1号機、マルチCPU2号機、マルチCPU3号機、マルチCPU4号機、リモートヘッド1号機、リモートヘッド2号機、制御系リモートヘッド、待機系リモートヘッドから選択します。自局CPUに接続する場合は、自局を選択してください。

タイミング

監視周期 ms
PLC の値を読み取る間隔です。100～10000 ms で指定します。既定値は 500 ms です。
タイムアウト ms
PLC からの応答を待つ時間です。250～10000 ms で指定します。既定値は 2000 ms です。

Demoの値変化パターン

この項目はデモの場合のみ設定できます。

Demoプロジェクトでは、アプリ内で生成された監視値が変化します。PLC 設定の 値変化パターン で、画面表示やトラップ確認に使う変化の出方を選べます。

スイープ
BIT は周期的に ON/OFF し、数値は 0 から 100 へ繰り返し変化します。
パルス
短い瞬間的な変化を出します。立上り、立下り、変化検出のトラップ確認に向いています。
ウェーブ
なめらかな波形で数値が上下します。タイムチャートで値の推移を確認できます。
ステップ
段階的に値が切り替わります。しきい値付近やトラップ条件を確認できます。
固定
自動変化を止め、現在値を保持します。

Demoの値は実機 PLC の状態を表すものではありません。値変化パターンはプロジェクト JSON には含まれません。

デバイス表記

利用可能なデバイス

X、Y、M、D、L、F、B、SB、SM、STC、STN、TC、TN、CC、CN、W、SW、R、ZR、SD

X / Y

iQ-F は 8 進表記です。それ以外の MELSEC は 16 進表記です。

BIT
BIT デバイス用です。ON/OFF として扱います。
INT16 / UINT16
16 bit の符号付き整数／符号なし整数として扱います。
INT32 / UINT32 / FLOAT32
32 bit の符号付き整数／符号なし整数／浮動小数点数として扱います。

選択中の CPU機種で使えないアドレスやデータタイプは、登録時や読込時にエラーになります。

実機接続の注意

接続すると PLC との通信が始まります。接続前に対象 PLC、IP、ポート、TCP/UDP、通信許可、ネットワーク経路を確認してください。

デバイス書込や CPU操作は設備動作に影響します。設備側の安全手順に従って操作してください。

接続結果の見方

  • 接続成功時は上部ステータスに RUN/STOP、CPU、IP、プロジェクト名が表示されます。
  • 未接続時の CPU 状態は -- と表示されます。
  • 接続できない場合は 到達確認 を実行し、IP、ポート、TCP/UDP、端末のネットワーク接続を確認してください。
  • ネットワーク、局番、ユニット I/O、リモートパスワードも確認してください。
  • PLC 側の設定や通信許可は 接続設定例 と照らし合わせてください。

到達確認のエラー例

タイムアウト
PLC から応答がありません。IP アドレス、ポート、通信方式、端末のネットワーク接続を確認してください。
接続拒否
PLC 側が接続を受け付けていません。ポートと PLC 側の通信設定を確認してください。
認証エラー
リモートパスワードを確認してください。
ルーティングエラー
ネットワーク、局番、ユニットI/Oを確認してください。
