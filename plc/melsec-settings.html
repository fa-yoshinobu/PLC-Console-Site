MELSEC

MELSEC 設定

MELSEC 実機または MELSEC デモ案件で使う通信設定と表記ルールです。

実行条件と入口

  1. 入口上部タイトルをタップして 接続先切替 を開き、MELSEC 実機または MELSEC デモを選びます。
  2. 設定接続設定 で IP、Port、機種、通信、ルーティング、タイミングを確認します。
  3. 結果接続後は上部ステータスに RUN/STOP、CPU model、IP、案件名が表示されます。

通信設定

通信方式
SLMP
既定ポート
1025
通信
TCP / UDP
機種
iQ-R、iQ-F、iQ-L、MX-R、MX-F、QnUDV、QnU、QCPU、LCPU
リモートパスワード
MELSEC 専用です。KEYENCE 案件では出力しません。

ルート指定

network
10 進表記
station
10 進表記
module_io
16 進表記。Project JSON では 0x 付き 16 進文字列です。
multidrop
16 進表記。Project JSON では 0x 付き 16 進文字列です。

アドレス表記

  • B、W、SB、SW は 16 進表記です。
  • iQ-F の X / Y は 8 進表記です。
  • それ以外の MELSEC X / Y は 16 進表記です。
  • BIT デバイスの data type は BIT、WORD デバイスは INT16、UINT16、INT32、UINT32、FLOAT32 を使います。
