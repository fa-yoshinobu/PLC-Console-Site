KEYENCE 設定

KEYENCE で使う接続設定、デバイス表記、コメント読込です。

開き方と確認内容

  1. 開く上部ステータス部分をタップして 接続先切替 を開き、KEYENCE の接続先を選びます。
  2. 確認接続設定 で IP、Port、機種、通信、タイミングを確認します。
  3. 接続後上部ステータスに RUN/PROGRAM、CPU機種、IP、プロジェクト名が表示されます。

接続設定

通信方式
Host-link（上位リンク）
PLC IP / Port
PLC 側の Ethernet 設定に合わせます。既定ポートは 8501 です。
通信
TCP / UDP
機種
KEYENCE KV-NANO、KEYENCE KV-NANO (XYM)、KEYENCE KV-3000、KEYENCE KV-3000 (XYM)、KEYENCE KV-5000、KEYENCE KV-5000 (XYM)、KEYENCE KV-7000、KEYENCE KV-7000 (XYM)、KEYENCE KV-8000、KEYENCE KV-8000 (XYM)、KEYENCE KV-X500、KEYENCE KV-X500 (XYM)
到達確認
入力した接続設定で確認を実行し、結果とエラーメッセージを確認します。

PLC 側の Ethernet 設定と通信許可は 接続設定例 で確認します。

タイミング

監視周期 ms
PLC の値を読み取る間隔です。100～10000 ms で指定します。既定値は 500 ms です。
タイムアウト ms
PLC からの応答を待つ時間です。250～10000 ms で指定します。既定値は 2000 ms です。

Demoの値変化パターン

この項目はデモの場合のみ設定できます。

Demoプロジェクトでは、アプリ内で生成された監視値が変化します。PLC 設定の 値変化パターン で、画面表示やトラップ確認に使う変化の出方を選べます。

スイープ
BIT は周期的に ON/OFF し、数値は 0 から 100 へ繰り返し変化します。
パルス
短い瞬間的な変化を出します。立上り、立下り、変化検出のトラップ確認に向いています。
ウェーブ
なめらかな波形で数値が上下します。タイムチャートで値の推移を確認できます。
ステップ
段階的に値が切り替わります。しきい値付近やトラップ条件を確認できます。
固定
自動変化を止め、現在値を保持します。

Demoの値は実機 PLC の状態を表すものではありません。値変化パターンはプロジェクト JSON には含まれません。

機種とデバイス表記

Normal

機種名に (XYM) が付かない機種です。R、B、MR、LR、CR、DM、EM、FM、ZF、W、TM、CM を扱います。

XYM

機種名に (XYM) が付く機種です。B、CR、ZF、W、TM、CM、X、Y、M、L、D、E、F を扱います。

BIT
BIT デバイス用です。ON/OFF として扱います。
INT16 / UINT16
16 bit の符号付き整数／符号なし整数として扱います。
INT32 / UINT32 / FLOAT32
32 bit の符号付き整数／符号なし整数／浮動小数点数として扱います。

選択中の機種で使えないアドレスやデータタイプは、登録時や読込時にエラーになります。

コメント読込

KEYENCE プロジェクトでは、接続中にメニューの コメント読込 が使用できます。表示中のみ読込、デバイス単位の範囲選択、デバイス操作パネルからの個別読込を使えます。

未接続時や対応しない接続では実行できません。読込中は進捗と残り割合が表示され、結果はステータスとエラー履歴で確認します。

実機接続の注意

接続すると PLC との通信が始まります。接続前に対象 PLC、IP、ポート、TCP/UDP、通信許可、ネットワーク経路を確認してください。

デバイス書込や CPU操作は設備動作に影響します。設備側の安全手順に従って操作してください。

接続結果の見方

  • 接続成功時は上部ステータスに RUN/PROGRAM、CPU、IP、プロジェクト名が表示されます。
  • 未接続時の CPU 状態は -- と表示されます。
  • 接続できない場合は 到達確認 を実行し、IP、ポート、TCP/UDP、端末のネットワーク接続を確認してください。
  • PLC 側の設定や通信許可は 接続設定例 と照らし合わせてください。

到達確認のエラー例

タイムアウト
PLC から応答がありません。IP アドレス、ポート、通信方式、端末のネットワーク接続を確認してください。
接続拒否
PLC 側が接続を受け付けていません。ポートと PLC 側の通信設定を確認してください。
