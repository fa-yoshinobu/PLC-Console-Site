JSON読込

保存済みのプロジェクトJSONを読み込み、現在のプロジェクトとして開きます。

画面概要

開き方
右上メニューから JSON読込 を開きます。
目的
バックアップ済み、または ProjectBuilder で作成したプロジェクトJSONを読み込みます。
対象
OS のファイル選択で指定した schemaVersion 2 の JSON ファイルです。上限は 5 MiB（5,242,880 bytes）です。
注意点
読込と検証に成功すると、現在のプロジェクトが読み込んだ内容へ切り替わります。失敗した場合、編集中のプロジェクトは変更されません。

読込手順

  1. JSON読込を開く右上メニューから JSON読込 を選びます。
  2. ファイルを選ぶOS のファイル選択で、読み込むプロジェクトJSONを指定します。
  3. 内容を確認するプロジェクト名、PLC 種別、接続先、登録デバイス、タイムチャートとトラップの登録数を確認します。

リモートパスワード

リモートパスワードはプロジェクトJSONには含まれません。必要な場合はモバイルアプリ側で入力してください。
