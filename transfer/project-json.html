Project JSON

project JSON

Android/iOS/ProjectBuilder で共有する案件 JSON と QR payload の現行仕様です。

現行形式

schema
plc-io-checker-project
schemaVersion
3
QR
PLCIOC3|ZSTD|<session>|<index>|<total>|<sha256>|<payload-chunk>
圧縮
Zstandard。payload は base64url 文字列を分割します。

主な top-level 項目

schema、schemaVersion、projectId、projectName、plc、deviceList、timeChart、traps、updatedAtEpochMs を持ちます。

MELSEC / KEYENCE の差分

MELSEC

plc.melsec に networkNo、stationNo、moduleIoNo、multidropNo、remotePassword を持ちます。moduleIoNo と multidropNo は 0x 付き 16 進文字列です。

KEYENCE

plc.keyence.deviceMode に NORMAL または XYM を持ちます。MELSEC の route 指定と remote password は出力しません。

互換方針

旧 QR 形式や無効値の silent fallback は行いません。読み込みに失敗した場合は JSON/QR を修正して再生成します。

value set

vendor
MELSEC、KEYENCE
connection.mode
REAL、DEMO_MOCK
transport

dataType
BIT、INT16、UINT16、INT32、UINT32、FLOAT32
trap.condition
RISING_EDGE、FALLING_EDGE、CHANGE、GREATER_OR_EQUAL、LESS_OR_EQUAL、EQUAL、NOT_EQUAL
