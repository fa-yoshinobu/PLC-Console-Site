Project Builder のインストール

1

EXEファイルをダウンロード

ダウンロードページ から PlcIoCheckerQr.exe をダウンロードします。

インストーラーは不要です。EXEをダブルクリックするだけで起動します。

2

起動確認

ダウンロードした PlcIoCheckerQr.exe をダブルクリックします。Windows Defender のスマートスクリーンが表示された場合は「詳細情報」→「実行」をクリックしてください。

3

言語設定（任意）

メニューの「Settings」から表示言語を「日本語」または「English」に変更できます。

プロジェクトの作成

1

新規プロジェクトを作成

「新規」ボタンをクリックし、プロジェクト名を入力します。

2

PLCベンダーを選択

「Mitsubishi MELSEC」または「KEYENCE KV」を選択します。

3

接続情報を入力

PLCのIPアドレスとポート番号を入力します。

項目説明デフォルト
IPアドレスPLCのEthernetモジュールIPアドレス192.168.3.39
ポートSLMP (MELSEC) または HostLink (KEYENCE)5001 / 8501
トランスポートUDP または TCPUDP
タイムアウト通信タイムアウト（ms）1000

MELSECの場合、GX Works等でSLMP通信を有効にしておく必要があります（詳細は「MELSEC Ethernet設定」参照）。

4

MELSECルーティング設定（iQ-R / Q系のみ）

マルチCPU構成の場合、ネットワーク番号・PC番号・要求先ユニットI/O番号・要求先ユニット局番号を設定します。通常は ネットワーク: FF / PC: FF のデフォルトで動作します。

監視デバイスの登録

1

デバイスリストタブを選択

「デバイスリスト」タブで監視対象のデバイスアドレスを登録します。

2

デバイスを追加

「追加」ボタンでアドレスとデータ型を入力します。または、Excelのアドレス列をコピーして「貼り付け」で一括登録できます。

データ型サイズ例
Bit1ビットM0, X0, Y10
Int1616bit符号付き整数D100
UInt1616bit符号なし整数D100
Int3232bit符号付き整数D200 (2ワード)
UInt3232bit符号なし整数D200 (2ワード)
Float32単精度浮動小数点D300 (2ワード)
3

コメント（ラベル）を設定

各デバイスにコメント（説明文）を付けられます。アプリ上でデバイスを識別しやすくなります。CSVでインポートも可能です。

4

タイムチャートターゲット（任意）

「タイムチャート」タブで最大20chの波形記録ターゲットを登録します。アドレスとデータ型を設定してください。

5

トラップルール（任意）

「トラップ」タブで監視条件を設定します。

条件タイプ説明
Rising Edge0→1に変化したとき
Falling Edge1→0に変化したとき
Change値が変化したとき
>= / <= / == / !=しきい値との比較

QRコードの生成とエクスポート

1

QRコード生成ボタンをクリック

設定が完了したら「QRコード生成」ボタンをクリックします。

2

QRコードを確認

登録デバイス数が多い場合、1枚のQRに収まらないことがあります。その場合は複数枚のQRが生成されます。チャンクサイズ（200〜2400文字）とエラー訂正レベル（L/M/Q/H）を調整してQRの密度を変更できます。

読み取りやすさを優先する場合は、チャンクサイズを小さくしてQR枚数を増やすことをお勧めします。

3

PNG でエクスポート（任意）

「PNG出力」ボタンでQRコード画像をファイルに保存できます。メールで現場担当者に送付したり、印刷して手渡しする場合に便利です。

4

JSONでエクスポート（任意）

「JSONエクスポート」でプロジェクト設定ファイルとして保存できます。次回以降、Project Builderで「JSONインポート」から設定を再利用できます。

アプリへの設定インポート

1

アプリを起動してプロジェクト画面を開く

PLC IO Checker を起動し、「新規プロジェクト」または「QRスキャン」を選択します。

2

QRコードをスキャン

カメラを起動してProject Builderで生成したQRコードを読み取ります。複数枚QRの場合は、表示されている枚数分すべてをスキャンしてください。

QRの順番はどの順でスキャンしても構いません。アプリが自動的に順序を判断して結合します。

3

設定を確認して保存

インポートしたPLC接続情報・デバイスリスト・トラップルールを確認し、プロジェクトを保存します。

PLCへの接続

1

Wi-Fiに接続

スマートフォンをPLCと同一ネットワークのWi-Fiに接続します。PLCが工場LANにある場合は、そのネットワークに接続してください。

2

接続ボタンをタップ

アプリ上部の「接続」ボタンをタップします。接続に成功すると、ステータスバーにCPU型式とIPアドレスが表示されます。

3

デモモードで試す（実機なし）

「デモモード」を選択すると、実際のPLCなしで全機能を評価できます。デバイス値はシミュレーションデータで動作します。

デバイス監視と操作

1

デバイスリスト — 値をリアルタイム確認

登録したデバイスの現在値が一覧表示されます。フィルタ・グループタブ・検索バーで目的のデバイスをすばやく見つけられます。

2

フォーカスパネル — 値を読み書き

デバイスをタップするとフォーカスパネルが開きます。ビットデバイスはON/OFFボタンで操作、ワードデバイスは数値を入力して書き込めます。

書き込み操作は実際のPLC出力に即時反映されます。安全を確認してから操作してください。

3

ブロック監視 — 連続アドレスを一覧表示

「ブロック」ビューに切り替えると、設定したアドレスレンジをまとめて監視できます。コンパクト表示と詳細表示を切り替えられます。

タイムチャートの使い方

1

タイムチャートビューに切り替え

画面下部のタブから「チャート」を選択します。

2

チャンネルを確認

Project Builderで設定した最大20chのデバイスが波形表示されます。各チャンネルの色・Y軸スケールを個別に調整できます。

3

記録の確認

タイムチャートは 500ms サンプリングで最大 1000サンプル（約500秒） を自動記録します。スワイプで過去のデータを確認できます。

4

CSVエクスポート

「CSV出力」ボタンで記録データをCSVファイルとして保存・共有できます。Excelでの解析に活用できます。

トラップ（アラート）の設定と確認

1

トラップビューに切り替え

画面下部のタブから「トラップ」を選択します。

2

イベント履歴を確認

設定した条件が成立すると、タイムスタンプ・デバイスアドレス・値がイベントリストに記録されます。

3

CSVエクスポート

イベント履歴をCSVファイルとして出力できます。不具合解析・品質記録に活用できます。

MELSEC Ethernet設定手順

GX Works2 / GX Works3 でのEthernetモジュール設定手順です。

iQ-R / iQ-F 系（GX Works3）

1

パラメータ設定を開く

GX Works3 → 「パラメータ」→「モジュール情報」からEthernetモジュール（RJ71EN71等）を選択

2

IPアドレスを設定

「基本設定」→「自局IPアドレス」にPLCのIPアドレスを設定します。
例: 192.168.3.39

3

SLMP通信を有効化

「外部デバイス構成」→「SLMP接続機器」に接続元IPアドレスを登録します。
または「オープン設定」でUDPポート 5001 の通信を許可します。

iQ-F（FX5U）の場合、「Ethernetポート内蔵」→「プロトコル: SLMP」→「ポート番号: 5001」を設定してください。

4

パラメータを書き込んでリセット

設定をPLCに書き込み、PLCを再起動（RESETまたは電源OFF/ON）します。

Q系 / L系（GX Works2）

1

パラメータ → ネットワークパラメータ

GX Works2 → 「パラメータ」→「ネットワークパラメータ」→「Ethernet/CCIEF」を選択

2

IPアドレスとオープン設定

ユニットIPアドレスを設定し、「オープン設定」でプロトコル「UDP」、固定バッファ通信を設定します。
通信ポート番号: 5001（SLMP）

3

パラメータ書き込みと初期化

パラメータをPLCに書き込み、電源を再投入します。LED（OPEN）点灯を確認します。

アプリ側の設定値（MELSEC）

ベンダーMitsubishi MELSEC
プロトコルSLMP（UDP推奨）
ポート5001（デフォルト）
タイムアウト1000ms（推奨）

KEYENCE Ethernet設定手順

KV STUDIO を使ったEthernet設定手順です。

1

ユニット設定を開く

KV STUDIO → 「ユニット設定」からKVシリーズの内蔵EthernetまたはEthernetユニットを選択

2

IPアドレスを設定

「IPアドレス」に接続先PLCのIPを設定します。
例: 192.168.3.100
サブネットマスク・デフォルトゲートウェイもネットワーク環境に合わせて設定します。

3

HostLink通信を有効化

「通信設定」でHostLink通信（TCP）を有効にします。
通信ポート番号: 8501（デフォルト）

KV-X500 / KV-8000 / KV-7000 / KV-5000 はEthernet内蔵のため、別途Ethernetユニットは不要です。

4

設定を転送してPLCを再起動

KV STUDIOから設定をPLCに転送し、PLCを再起動します。

アプリ側の設定値（KEYENCE）

ベンダーKEYENCE KV
プロトコルHostLink（TCP）
ポート8501（デフォルト）
タイムアウト2000ms（推奨）

接続エラーと対処法

エラー・症状 考えられる原因と対処
接続できない / タイムアウト ① IPアドレス・ポート番号が正しいか確認
② スマートフォンとPLCが同じネットワーク（Wi-Fi）か確認
③ PLC側のファイアウォール設定を確認
④ Pingコマンドで疎通確認（PC → PLC）
接続成功したがデバイス値が読めない ① SLMPまたはHostLinkの通信設定が有効か確認
② PLCのCPU状態（STOP中は一部デバイス制限あり）
③ デバイスアドレスが存在するか確認
値の書き込みができない ① PLCがRUN中か確認（強制書き込みが必要な場合あり）
② 書き込み禁止デバイス（T/C現在値など）でないか確認
③ MELSECの場合、ユニット側の書き込み保護設定を確認
QRスキャンができない ① カメラ権限がアプリに付与されているか確認（スマートフォン設定）
② QRが多ページの場合、すべてのページをスキャンしたか確認
③ QRコードの印刷が鮮明か確認（チャンクサイズを小さくしてQRの密度を下げる）
タイムチャートが表示されない Project Builderのタイムチャートタブでチャンネルを登録し、QRを再生成してアプリにインポートしてください。
MELSEC iQ-F（FX5U）に接続できない プロトコルをUDP、ポートを5001に設定し、GX Works3でSLMP通信が有効かつ「コネクション設定」が完了しているか確認してください。
